# Site Nonna Pasta

Site vitrine de **Nonna Pasta** — trattoria italienne, 37 rue de Ponthieu, 75008 Paris.
*Il Sapore della Tradizione.*

## Ouvrir le site
Double-cliquez sur **`index.html`** — le site s'ouvre dans votre navigateur.

## Structure du projet
| Fichier / dossier | Rôle |
|---|---|
| `index.html` | La page du site |
| `styles.css` | La mise en forme (couleurs, design) |
| `script.js` | Les animations et fonctionnalités |
| **`config.js`** | **Le contenu à mettre à jour soi-même** (menu, sauce de la semaine, Click & Collect) |
| `GUIDE.html` | Mode d'emploi pas à pas pour les mises à jour |
| `assets/images/` | Les photos du site |
| `assets/favicon.svg` | La petite icône de l'onglet du navigateur |

## Mettre à jour le contenu
Tout se passe dans **`config.js`** (à ouvrir avec le Bloc-notes). Voir le **`GUIDE.html`** pour :
- changer la **sauce de la semaine** ;
- changer une **photo** du menu ;
- modifier / ajouter / retirer un **plat** ;
- activer le **Click & Collect** quand le lien de commande (L'Addition) sera prêt.

> 💡 Astuce : après chaque modification, enregistrez le fichier puis rechargez la page (F5).
