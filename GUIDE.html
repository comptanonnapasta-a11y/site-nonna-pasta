Guide de mise à jour

Site Nonna Pasta · simple, sans connaissances techniques

Bonne nouvelle : pour le quotidien, vous ne modifiez qu'un seul fichier : config.js. Ouvrez-le avec le Bloc-notes (clic droit → Ouvrir avec → Bloc-notes). Changez uniquement le texte entre les guillemets " ", enregistrez, puis rechargez la page (touche F5).

⚠️ Ne supprimez jamais les guillemets ", les virgules ,, les crochets [ ] ni les accolades { }. Ils font tenir la page ensemble.

1. Changer la sauce de la semaine

Dans config.js, tout en haut, trouvez la ligne : 
sauceDeLaSemaine: "Crème de truffe & parmesan",
Remplacez le texte entre guillemets par la sauce du moment. Exemple : 
sauceDeLaSemaine: "Pesto maison & pignons",
Enregistrez, rechargez la page : le titre de la section « Sauce de la semaine » est à jour. ✅
💡 Les petits boutons de sauces se règlent juste en dessous, dans la liste sauces: [ ... ]. Ajoutez ou retirez des noms, chacun entre guillemets et séparé par une virgule.

2. Changer une photo du menu

La méthode la plus simple (recommandée) :
  1. Ouvrez le dossier assets/images/.
  2. Repérez la photo à remplacer, par exemple pizza.jpg.
  3. Renommez votre nouvelle photo avec exactement le même nom (pizza.jpg) et déposez-la dans le dossier en écrasant l'ancienne.
  4. Rechargez la page. La nouvelle photo apparaît. ✅
💡 Idéalement, utilisez une photo au format paysage (plus large que haute) pour un joli rendu. Les grandes photos sont automatiquement redimensionnées à l'affichage.

3. Changer le nom, la description ou la catégorie d'un plat

Dans config.js, section menu, chaque plat est un bloc comme celui-ci : 
{
  categorie: "pizza",
  image: "pizza.jpg",
  badge: "",
  nom: "Pizza dinde & champignons",
  description: "Pâte fine, mozzarella, dinde, champignons frais et roquette."
},
Modifiez le texte entre guillemets. badge = petite étiquette (ex. "Signature") ; laissez "" si vous n'en voulez pas. categorie doit être l'un de : "pates", "salades", "pizza", "desserts", "boissons".

4. Ajouter ou retirer un plat

Ajouter : copiez un bloc { ... } entier (avec sa virgule), collez-le juste après, puis changez son contenu et le nom de sa photo.

Retirer : supprimez le bloc { ... } du plat concerné (et la virgule qui le suit).

Besoin d'aide ?

En cas de doute, faites d'abord une copie de config.js (copier-coller le fichier) avant de le modifier : si quelque chose ne s'affiche plus, vous pourrez revenir à la version qui marchait. Vous pouvez aussi me redemander une modification à tout moment.
